# Project guidance for Codex

When the user asks about Java lambdas, predefined functional interfaces,
collections, or the exercises in this repository, read
`docs/learning-context.md` before answering or editing files.

Use the teaching approach recorded there. Also read the specific requirement or
solution document relevant to the current topic instead of relying on conversation
memory.

When a new functional-interface topic is completed or the learning workflow
materially changes, update `docs/learning-context.md` so a future session can
continue without reconstructing the conversation.

Do not overwrite the user's exercise solutions merely to match the reference
solutions. Inspect first, explain the differences, and edit only when the user
asks for or clearly authorizes a revision.
